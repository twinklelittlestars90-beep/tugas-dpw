# TaskFlow - React To-Do List

## Menjalankan proyek
1. Ekstrak file ZIP.
2. Buka folder `taskflow` di VS Code.
3. Buka terminal pada folder proyek.
4. Jalankan `npm install`.
5. Jalankan `npm run dev`.
6. Buka alamat lokal yang ditampilkan terminal, biasanya http://localhost:5173.

## Fitur
- Dashboard statistik tugas.
- Tambah tugas dengan deskripsi, kategori, dan tenggat.
- Tandai tugas selesai atau belum selesai.
- Hapus tugas.
- Filter tugas.
- Navigasi Dashboard, Daftar Tugas, Tentang, dan halaman 404.

## Materi React
Komponen, modularisasi data, Props, destructuring, useState, array state, event handling, passing function, map(), filter(), key, BrowserRouter, Routes, Route, Link, dan NavLink.

Catatan: data tugas disimpan dalam state aplikasi. Saat browser di-refresh, perubahan akan kembali ke data awal. Penyimpanan permanen belum ditambahkan agar fokus tetap pada materi praktikum.
